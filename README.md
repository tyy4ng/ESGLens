# ESG Report Analysis Pipeline

A research pipeline that extracts structured ESG (Environmental, Social, and Governance) information from corporate sustainability reports using LLMs, and trains a BERT regression model to predict LSEG Environmental scores from report text.

---

## Pipeline Overview

```
Step 0: Fetch LSEG ESG scores (ground-truth labels)
        esg_0_get_esg_score_LSEG.py
                │
                ▼
        LSEG_Score.csv

Step 1a: Process ESG report PDFs (batch)
        esg_1_multi-files.py
                │
                ▼
        esg_summary/summary_df/<report>/
            summary_context.csv
            summary_tone.csv
            summary_numeric.csv

Step 1b: Process a single ESG report PDF (for testing)
        esg_1_single_file.py

Step 2: Prepare ML training dataset
        esg_2_dataprocessing.py
                │  (reads LSEG_Score.csv + summary_context.csv)
                ▼
        ESG_summary_and_LSEG_Score.csv

Step 3: Train BERT regression model
        esg_3_score.py
                │  (reads ESG_summary_and_LSEG_Score.csv)
                ▼
        esg_bert_regressor.pt
```

---

## File Structure

```
├── esg_documents.py             # Core module: PDF parsing, FAISS vector store, 
├── esg_0_get_esg_score_LSEG.py  # Fetch ESG scores from Refinitiv/LSEG API
├── esg_1_multi-files.py         # Batch-process ESG PDF reports with LLM
├── esg_1_single_file.py         # Process a single ESG PDF report (for testing)
├── esg_2_dataprocessing.py      # Build ML training dataset from summaries + LSEG scores
├── esg_3_score.py               # Fine-tune BERT regression model
│
├── esg_report/
│   └── <EXCHANGE>_<TICKER>_<YEAR>.pdf   (e.g. NASDAQ_AAPL_2022.pdf)
│
├── esg_tickers/                 # Ticker list CSVs (optional, used by Step 0)
│   ├── SP500.csv
│   └── Russell1000.csv
│
└── esg_summary/                 # Auto-generated by the pipeline
    ├── vector_db/               # FAISS vector stores (one per report)
    ├── retrieved_chunks/        # Retrieved chunks saved as JSON (for auditing)
    └── summary_df/              # LLM-extracted summaries (one folder per report)
```

## Requirements

### Python version
Python 3.9+

### Install dependencies

```bash
pip install -r requirements.txt
```

**Core dependencies:**

| Package | Purpose |
|---------|---------|
| `refinitiv-data` | Fetch ESG scores from LSEG/Refinitiv API (Step 0) |
| `langchain` | PDF chunking, vector store, LLM orchestration |
| `openai` | OpenAI Embeddings + GPT-4o-mini |
| `faiss-cpu` | Vector similarity search |
| `PyMuPDF` | PDF parsing (`import fitz`) |
| `torch` | BERT model training |
| `transformers` | BERT tokenizer and model |
| `scikit-learn` | Train/test split |
| `pandas` | Data processing |
| `matplotlib` | Score distribution plots |

### Environment variables

Set your OpenAI API key before running any script:

```bash
export OPENAI_API_KEY="your-api-key-here"
```

> **Note:** Never hard-code API keys in source files.

## Step-by-step Usage

### Step 0 — Fetch LSEG ESG scores

Requires a Refinitiv/LSEG Data subscription.

```bash
python esg_0_get_esg_score_LSEG.py
```

- Tickers are derived from PDF filenames in `esg_report/` by default.
- To use a pre-defined index instead, edit the `Settings` section at the top of the file and uncomment the relevant `get_*_tickers()` call.
- Output: `LSEG_Score.csv`

---

### Step 1 — Extract ESG information from PDFs

**Batch (all reports):**

```bash
python esg_1_multi-files.py
```

**Single report (for testing):**

```bash
python esg_1_single_file.py
```

Edit `PDF_PATH` at the top of `esg_1_single_file.py` to point to your target PDF.

- Each report produces three CSVs under `esg_summary/summary_df/<report_name>/`:
  - `summary_context.csv` — key content points with source page numbers
  - `summary_tone.csv` — tone classification (Positive / Neutral / Negative)
  - `summary_numeric.csv` — extracted numerical values

---

### Step 2 — Prepare training dataset

```bash
python esg_2_dataprocessing.py
```

- Reads `LSEG_Score.csv` and all `summary_context.csv` files.
- Pairs each report's text with its LSEG Environmental (E) Score.
- Assigns a category label: `0` (< 50), `1` (50–75), `2` (> 75).
- Output: `ESG_summary_and_LSEG_Score.csv`

---

### Step 3 — Train BERT regression model

```bash
python esg_3_score.py
```

- Reads `ESG_summary_and_LSEG_Score.csv`.
- Fine-tunes a regression head on top of a frozen `bert-base-uncased` encoder.
- Output: `esg_bert_regressor.pt`

## ESG Query Categories

The pipeline extracts information across 18 predefined ESG questions grouped into six categories:

| Category | Keys | Description |
|----------|------|-------------|
| Basic | `basic_1` | Company sector |
| Emissions | `emissions_1` – `emissions_4` | GHG emissions, carbon intensity, reduction targets, air pollutants |
| Resources | `resource_1` – `resource_4` | Energy, water, raw materials, waste |
| Environment | `environment_1` – `environment_3` | Green products, R&D investment, circular economy |
| Biodiversity | `biodiversity_1` – `biodiversity_3` | Policies, conservation projects, supply chain impact |
| EMS | `ems_1` – `ems_3` | Environmental policies, certifications, transparency |

## PDF Naming Convention

PDF files must follow this naming format for ticker extraction to work correctly:

```
<EXCHANGE>_<TICKER>_<YEAR>.pdf
```

Examples:
```
NASDAQ_AAPL_2022.pdf
NASDAQ_AMZN_2022.pdf
NASDAQ_MSFT_2022.pdf
NASDAQ_NFLX_2022.pdf

```

## Notes

- The FAISS vector store is rebuilt from scratch on every run. Caching (loading from `db_path` if it exists) can be enabled by modifying `_get_retriever()` in `esg_documents.py`.
- LLM calls use `gpt-4o-mini` by default. This can be changed via the `LLM_NAME` constant at the top of each script.
- Failed reports are collected in `failed_files` and printed at the end of the batch run — no partial results are lost.
